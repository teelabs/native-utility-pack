# Expo Web capability showcase

This app renders the package's real `ReelPicker` component through Expo Web. It demonstrates controlled state, numeric bounds, tap and swipe callbacks, formatting, style customization, accessibility copy, and reduced-motion behavior.

From the repository root:

```bash
npm run build
cd examples/showcase
npm install
npm run web
npm run build:web
```

The static output is written to `examples/showcase/dist` for GitHub Pages deployment.
